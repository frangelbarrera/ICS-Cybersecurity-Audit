# Contributing to ICS-Cybersecurity-Audit

Thanks for your interest in improving this ICS/OT security methodology!

## How to Contribute

### Improving Methodology or Checklists

1. Fork the repository
2. Make your changes to the relevant section in README.md or docs/
3. Ensure changes align with IEC 62443 and/or NIST SP 800-82 standards
4. Submit a pull request with a clear description of what was added or corrected

### Adding Protocol Security Guides

1. Follow the existing table format in the OT Protocol Security Guides section
2. Include: Protocol name, default port, security risks, and hardening recommendations
3. Cite relevant standards or advisories (CISA ICS-CERT, vendor documentation)
4. Submit a pull request

### Reporting Errors or Outdated Information

Open an issue with:
- Title: "Error: [section name]" or "Outdated: [section name]"
- The current text and the suggested correction
- Any supporting references (standards, advisories, vendor docs)

## Guidelines

- This is a **defensive security** resource — no exploit code or offensive tool instructions
- All contributions must respect IEC 62443, NIST SP 800-82, and applicable regulations
- Cite authoritative sources for any technical claims
- Keep formatting consistent with existing sections
- Do not include proprietary or classified information
- Contributions are licensed under CC BY-NC-SA 4.0

## Security Vulnerability Reporting

If you discover a vulnerability in an ICS/OT product referenced in this guide, do NOT report it here. Report it directly to the vendor and to CISA ICS-CERT following responsible disclosure practices.
